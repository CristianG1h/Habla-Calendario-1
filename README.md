# Habla Calendario

Prototipo estático de agenda con lectura de eventos mediante la síntesis de voz del navegador. En esta copia, las páginas están en la raíz del repositorio.

1. Abre [Bienvenida.html](Bienvenida.html) en el navegador.
2. Explora la agenda en [Inicio.html](Inicio.html).
3. En [evento.html](evento.html), completa un evento de prueba y usa el botón de voz para escuchar sus datos.

El proyecto incluye pantallas de demostración de acceso, registro y comentarios. Prueba los formularios con datos ficticios.
